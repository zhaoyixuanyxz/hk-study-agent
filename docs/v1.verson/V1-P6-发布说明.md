# V1 发布说明（试用版）

**面向对象**：内测用户 / 家长与学生（简化说明）  
**版本**：v1.0

---

## 本次提供的能力

1. **专业建档对话（Chat）**：用简短对话补齐申请背景；可看到建档进度与报告准备度提示。  
2. **申请档案（Profile）**：查看已确认与待确认信息、缺口对方案/报告的影响。  
3. **申请策略（Plan）**：冲刺 / 匹配 / 保底与预算、时间线、风险提示；依据可带来源引用。  
4. **正式报告（Report）**：结构化短报告、家长摘要与行动计划；支持 **PDF 下载**（视部署环境而定）。  
5. **交付历史（History）**：报告版本、分享状态、再次下载 PDF。  
6. **香港留学情报（Intelligence）**：按院校浏览、搜索与筛选、AI 摘要（带来源）、关注院校后的提醒入口。

---

## 使用上的限制（重要）

- **不是**录取或签证担保工具，结论仅供参考，请以院校官方与当局最新政策为准。  
- **不包含**：多方案对比、付费下单、人工顾问后台、自动网申投递等。  
- **模型与数据**：无 API 密钥时部分 AI 能力为演示/mock；情报数据依赖来源白名单与更新任务，**务必核对原文链接**。  
- **隐私**：公开分享链接可被持有链接的人阅读，请勿随意转发；可随时在报告中关闭分享。
