# V1 错误监控说明

**版本**：v1.0（V1-P6）  
**目的**：约定「可观测」失败点，便于接入日志平台 / Sentry / 自研告警。**当前 MVP 多为 `console.error` + HTTP 状态码**，以下为对照表。

---

## 1. 按功能域

| 域 | 典型失败 | HTTP / 行为 | 日志或排查 |
|----|----------|----------------|------------|
| **PDF** | Chromium 不可用、超时 | `501`（`PDF_DISABLED`）、`5xx` | 检查 `PDF_DISABLED`、`PUPPETEER_EXECUTABLE_PATH`；`pdf-service` 抛错会在 Fastify 500 |
| **报告分享** | token 无效、已关闭 | `404`（公开页 HTML） | 业务预期内；异常飙升需防扫描 |
| **情报采集** | `intelligence-daily.mjs` 抓取失败 | 进程退出码非 0 / 控制台输出 | 查 `INTELLIGENCE_FETCH`、网络、白名单 URL；脚本内应有错误栈 |
| **情报检索** | 参数错误 / 存储损坏 | `400` / `500` | `GET /api/v1/intelligence/search` |
| **情报摘要** | 模型不可用、校验失败 | `4xx`/`5xx`（视实现） | `POST .../search/summary`；无密钥时走 Mock，失败率应极低 |
| **鉴权** | 缺 Token、无效 Token | `401` | 统一 `code`: `unauthorized` / `invalid_token` |
| **越权** | 访问他人资源 | `404` | `thread_not_found` / `plan_not_found` 等（防枚举） |

---

## 2. 结构化日志（可选）

当设置 `ENABLE_ACCESS_LOG=1` 时，[backend/src/app.js](../../backend/src/app.js) 在响应结束时打印一行 JSON：`method`、`url`、`statusCode`、耗时 `ms`。适合集中采集做 5xx 率、P95 延迟。

方案生成失败时存在 `logPlanGenerationFailure` JSON 行（`scope: plan_generation`），可据此告警。

---

## 3. 接入外部监控时的建议字段

- **服务**：`study-abroad-agent-api`
- **环境**：`production` / `staging`
- **用户**：匿名可只哈希 `user_id`；勿上传 Bearer token。
- **fingerprint**：路由模板 + `code`（业务错误体）
