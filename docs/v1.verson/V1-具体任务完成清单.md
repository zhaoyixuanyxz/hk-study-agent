### V1-P1 验收标准

- Chat 回答简洁、专业，不出现明显模板化长篇。
- 用户能理解当前最重要的信息缺口。
- Chat 能解释为什么需要补充该信息。
- Chat 使用情报事实时带来源，不出现无来源结论。
