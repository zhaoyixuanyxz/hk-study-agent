# V1 埋点事件字典

**版本**：v1.0（V1-P6）  
**上报接口**：`POST /api/v1/analytics/events`（Bearer），body `{ "events": [{ "name": "...", "props": { ... } }] }`。  
**前端封装**：[frontend/src/track.js](../../frontend/src/track.js)；未登录时不发送。

---

## 1. 事件一览

| 事件名 | 触发时机 | props | 用途（统计） |
|--------|----------|-------|----------------|
| `nav_click` | 用户点击主导航切换 Tab | `to`: tab 名 | 各 Tab 使用深度 |
| `history_view` | 进入 History 面板 | 无 | 交付物中心访问 |
| `chat_message_send` | 发送一条用户消息 | `thread_id` | 对话活跃、Chat 完成率漏斗 |
| `plan_generate_click` | 点击生成方案 | 无 | 方案生成意向 |
| `plan_generate_result` | 方案生成结束 | `ok`, `code?` | 成功率与错误码 |
| `report_view` | 查看某报告 | `report_id` | 报告阅读 |
| `report_pdf_download` | 点击 PDF 下载 | `report_id` | 报告下载 |
| `report_share_enable` | 开启公开分享 | `report_id` | 分享启用 |
| `report_share_disable` | 关闭公开分享 | `report_id` | 分享撤回 |
| `report_generate_click` | 点击生成报告 | 无 | 报告生成意向 |
| `report_generate_result` | 报告生成结束 | `ok` | 成功率 |
| `auth_login_success` | 邮箱登录成功 | 无 | 账号登录 |
| `auth_register_success` | 邮箱注册成功 | 无 | 注册转化 |
| `intelligence_view` | 情报页渲染成功 | `view`: `dashboard` \| `school`，`school_id` | 情报渗透 |
| `intelligence_search` | 情报检索成功返回 | `q`, `school_id`, `total` | 搜索使用、结果规模 |
| `intelligence_summary_result` | AI 摘要请求结束 | `ok`, `citation_count?` | 摘要功能健康度 |
| `intel_follow_add` | 关注成功 | `kind`, `school_id` | 关注转化 |
| `intel_follow_remove` | 取消关注成功 | `kind`, `school_id` | 关注留存 |
| `thread_pin` | 在历史中置顶/取消置顶会话 | `thread_id`, `pinned` | 会话管理 |
| `thread_delete` | 删除咨询会话 | `thread_id` | 永久清除该会话下对话与关联建档数据（画像快照/记忆/方案/报告等，不可恢复） |

---

## 2. 与 V1-P6-OPS-01 的对应关系

- **Chat 完成率**：结合 `chat_message_send` 与后续 `plan_generate_result` / `report_generate_result` 构造漏斗（可加服务端会话状态事件作补充）。
- **报告下载 / 分享**：`report_pdf_download`、`report_share_enable` / `report_share_disable`。
- **情报搜索 / 关注**：`intelligence_search`、`intel_follow_add` / `intel_follow_remove`、`intelligence_summary_result`。

---

## 3. 存储与隐私

后端将事件写入 `analyticsEvents`（JSON DB），**勿**在 props 中放入密码、全文对话、报告 HTML。`client_ts` 由客户端写入 ISO 时间字符串（若后续在 `track` 中统一追加）。
