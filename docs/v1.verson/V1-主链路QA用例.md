# V1 主链路 QA 用例（可复测）

配合 [V1-阶段验收模板.md](V1-阶段验收模板.md) 使用；自动化覆盖见 `backend` 的 `npm run test:v1-p6`。

---

## V1-P6-QA-01 六 Tab 主链路

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 注册/登录进入 **Chat** | 可发消息，进度/就绪区有反馈 |
| 2 | 打开 **Profile** | 分区与事实状态可读 |
| 3 | **Plan** 在就绪后生成方案 | 三档卡片与引用区符合数据 |
| 4 | **Report** 生成报告 | HTML 可读；可下载 PDF（未 `PDF_DISABLED` 时） |
| 5 | **History** | 列表含该报告、分享状态正确 |
| 6 | **Intelligence** | 总览加载；检索有结果或空态提示；可进院校详情 |
| 7 | **历史 › 咨询会话**（可选） | 可 **置顶** / **取消置顶**；**删除** 会话后，**仅该会话**下产生的对话、摘要、建档快照、记忆、方案与报告从后端清除（不可恢复）；其他会话与无 `threadId` 的旧版快照不受影响 |

## V1-P6-QA-02 新用户首轮体验

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 新账号首次登录 | 默认进入 Chat，引导清晰 |
| 2 | 未完成建档时查看 Plan/Report | 有可读提示，告知需补齐项（或按钮禁用说明） |

## V1-P6-QA-03 家长分享体验

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | Report 页开启分享 | 得到链接；页面含 **隐私提示** |
| 2 | 浏览器隐身窗口打开分享 URL（无登录） | 仅见该报告内容，无用户 id、无其他报告 |
| 3 | 关闭分享后再次打开链接 | 404 或「不可用」提示 |

| 步骤 | 操作 | 预期 |
|------|------|------|

## V3-QA 情报 Admin（V3-INTEL）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 审核员登录，打开 **Intelligence › Admin** | 可见「检测链接」「安全采集」 |
| 2 | 点击「检测链接」 | 显示上次 preflight 摘要（成功/失败条数） |
| 3 | 点击「安全采集」 | Toast 含 ingested / skipped_preflight / errors |
| 4 | 普通用户 Tab 仅「刷新列表」 | 网络面板无 `POST .../admin/collect` |
| 5 | CLI：`cd backend && npm run intelligence:check-urls` | 与 Admin 探活结果一致 |

## V3-QA 聊天边界（V3-CHAT）
