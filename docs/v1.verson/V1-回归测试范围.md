# V1 回归测试范围

**版本**：v1.0  
**用途**：约束 V1-P1～P6 与发布前回归关注点；优先级 **P0** 阻塞上线，**P1** 应尽快修复。

---

## 1. 覆盖维度

| 维度 | P0（必测） | P1 |
|------|------------|-----|
| 六 Tab 主导航 | Chat / Profile / Plan / Report / History 主路径可走完；Intelligence 在落地后纳入同表 | Deep link、书签恢复、移动端布局 |
| 鉴权与安全 | Token 失效、匿名保护数据、线程 / 报告 / plan 归属 | 枚举 ID、限速、日志无敏感明文 |
| 公开分享报告 | Token 可读、撤回后不可用、仅此报告暴露 | 统计、CDN 缓存、隐私文案 |
| PDF | 生成成功、可复制文字、分页不截断标题 | 大页数、中英文混排字体 |
| Intelligence | 来源与链接可跳转、筛选正确、站内提醒准确性 | 大量数据性能、爬虫失败重试 |
| AI 与引用 | 知识库断言必带来源或无事实标记 | Prompt 漂移抽检 |
| 数据质量（情报） | 官方 / 媒体 / 平台三类标签可读、抽样链接有效 | 翻译误导项人工批次 |

## 2. 按 Tab 的场景矩阵（摘要）

| Tab | 场景示例 | 类型 |
|-----|----------|------|
| Chat | 多轮消息后建档进度刷新；就绪时短诊断出现 | 主链路 |
| Profile | 待确认事实与已确认分流；缺口影响文案 | 主链路 |
| Plan | `plans/generate` 前置不满足时错误可读；梯度卡片展示 | 主链路 |
| Report | HTML 查看；`/reports/:id` 越权访问 | 主链路 / 权限 |
| History | 列表与后端 `history` 一致；最新版标识 | 主链路 |
| Intelligence | Search + 摘要 citations；关注后提醒出现 | V1-P5 |
