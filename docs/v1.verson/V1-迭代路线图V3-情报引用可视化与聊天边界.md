## 一、V3 目标摘要

在 V2 内容产品化闭环之上，解决四类产品痛点：

1. **情报运维**：管理员「检测链接 → 安全采集」，不覆盖仍可用的旧内容  
2. **引用深度**：画像强关联 + 外链知识库，方案/报告 **≥6** 条可验证引用  
3. **可视化**：Plan/Report 结构化图表，缓解纯文字疲劳  
4. **聊天边界**：仅 **香港高校授课型硕士（Taught Master）** 规划  

**产品决策**：情报全量刷新 **仅审核员**；用户 Intelligence Tab 仅「刷新列表」。
