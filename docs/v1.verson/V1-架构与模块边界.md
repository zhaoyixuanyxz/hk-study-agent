# V1 架构与模块边界

**版本**：v1.0  
**阶段**：V1-P0  

本文定义后端 / 前端目标模块边界及与当前 MVP 代码的映射；**不要求**在本阶段完成物理搬迁。

---

## 1. 后端：目标模块与 MVP 映射

与 [V1-开发路线清单.md §3.1](V1-开发路线清单.md) 对齐的建议目录：

| 目标模块路径 | 职责 | MVP 现状（现有文件） | 迁移优先级建议 |
|----------------|------|----------------------|----------------|
| `backend/src/modules/chat-advisor/` | Chat 话术策略、建档进度、`readiness`、`prompt-policy` | `agent.js`, `promptLayer.js`, `orchestrator.js`, `app.js` 消息路由段 | P1 |
| `backend/src/modules/profile-dossier/` | 快照、事实确认、语义记忆、`plan-input-view` | `profile-service.js`, `plan-input-service.js`, `extraction.js`, `phase2-pipeline.js` | P2 |
| `backend/src/modules/planning-strategy/` | 方案生成前置条件与结构化 Plan | `planning-service.js`, `plan-generation-metrics.js` | P2 |
| `backend/src/modules/report-delivery/` | HTML 报告、PDF、分享令牌与访问控制 | `report-service.js`; PDF/分享：待实现 | P3 |
| `backend/src/modules/history-center/` | 聚合报告 / 方案列表与交付元数据 | `app.js` 中 `/history`、`/reports`、`/plans` 列表段；可薄封装 | P3 |
| `backend/src/modules/intelligence/` | 来源注册、入库、审核、检索、citation、关注与提醒 **（独立子系统）** | 无（V1-P4～P5 新建） | P4 |

**保持不变的核心支撑**（可先不移动）：`store.js`（JSON 持久化）、`password.js`、`index.js`、`app.js` 作为插件式路由注册聚合入口（远期瘦身）。

**Intelligence 隔离原则**：爬虫、规范化、索引与搜索不得写入 `report-service.js` 或 `agent.js` 深处；对外通过专用 service + store 中新集合字段消费。
