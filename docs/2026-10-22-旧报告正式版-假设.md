# Hypothesis: 旧报告不再当作正式版

## Hypothesis Statement

**We believe that** 报告里每一条学费、每一条截止日期都标上该条的抓取日期；学生画像或院校情报一变，已发出的旧报告就标为过期，重新生成之后才能再当作正式版发出去

**for** 已登录的学生，以及阅读该学生所发同一份报告的家长（本轮不加家长账号）

**will** 过期报告不再被拿去当正式选校和申请依据

**as measured by** 1 份标本、2 项对照全部通过：报告上每条学费和截止日期都看得到抓取日期；情报一更新，旧分享链接不再当作正式版

本假设只收这一件事。选校清单、申请路径、图表、香港授课型硕士边界不在本页展开。

## Background & Rationale

### Problem Context

目的已钉死，本页不重开四个空：用的人是学生和家长；交出来的是带更新时间的选校清单、能发出去的报告、核对过截止时间和学费的申请路径；不做本科、不做香港以外、不代写文书、不提交申请。现在只有学生账号。

这一条要证伪的是：画像或情报已经变了，旧报告仍能当作正式版发出去。学费和截止日期没有逐条抓取日期时，读者无法判断那一页还算不算数。

已有产品边界不另开文档：图表已在报告可视化里；顾问聊天的香港授课型硕士边界已在 V1 路线里。

### Supporting Evidence

写本页时核对过仓库里的现况，没有改代码：

- 情报快照有 `fetchedAt`（`backend/src/intelligence/real-crawler.js`、`normalization-service.js`）。结构化抽取能分出 `tuition` 与 `deadline`（`backend/src/intelligence/structured-extract.js`）。采集批次记在 `intelligenceCollectionRuns`（`backend/src/store.js` 的 `appendIntelligenceCollectionRun`）。每日脚本是 `backend/scripts/intelligence-daily.mjs`。
- 报告页前端没有展示逐条学费或截止日期的抓取日期。报告正文里的学费句子是「请以官网与当年汇率为准」这类提示（`backend/src/report-service.js`），不是该条数字的抓取日。
- 公开分享在链接仍开启时直接返回当时保存的 HTML（`backend/src/modules/core-routes.js`）。分享状态只有未分享、已分享、已关闭（`reportShareStatus`）。关闭是人手操作，不是画像或情报一变就过期。
- 历史列表的 `is_latest` 表示该用户最新生成的一份（`backend/src/modules/report-routes.js`），不表示旧链接已因情报或画像变化而失效。

因此：抓取日期停在情报库，没有落到可发出的报告上；旧链接在有人关闭之前一直是正式版。

### Alternative Hypotheses Considered

- 只在页脚加一句「数据可能已变化」：旧链接仍然能当正式版发出去，对不上这一条。
- 只显示情报条目的发布时间，不给每条学费和截止日期标抓取日期：读者仍看不出那一个数字是哪一天抓的。
- 先改报告文案、以后再补采集：没有对应的抓取记录时，文案上的日期是写出来的，不是核对过的。本页否掉这条。

## Target User Segment

### Definition

同时满足：

- 使用已有学生账号，本轮不新建家长账号
- 已经生成至少一份可浏览的报告，并曾打开或能够打开分享
- 报告里出现学费或截止日期，读者会把这份报告发给家长或自己留作申请依据

家长不另立账号。家长看到的是学生发出的同一份报告。

### Segment Size

未统计注册人数，本页不估流量。验证不按用户抽样，标本固定为 1 份：一个已有学生账号生成、且分享链接处于可打开状态的报告。

### Current Behavior

- 学生生成报告后可以打开公开链接；链接在人手关闭前一直返回原 HTML。
- 画像再谈细、情报再入库，都不会把已分享的旧报告标成过期。
- 读者在报告上看不到「这一条学费 / 这一条截止日期是哪一天抓的」。

## Success Metrics

### Primary Metric

| Metric | Current Baseline | Target | Minimum Detectable Effect |
|--------|-----------------|--------|--------------------------|
| 1 份标本上的正式版对照（2 项都过） | 0/2：报告上无逐条抓取日期；情报更新后旧链接仍可当正式版 | 2/2 | 不适用。标本对照，不估最小可检测效应，不做 A/B |

2 项对照：

1. 报告上每一条学费、每一条截止日期旁边都有抓取日期，日期能对上该条情报的 `fetchedAt`（或该次采集的 `finishedAt` 所在日历日）。页脚一句免责不算。
2. 情报更新之后，旧分享链接不再当作正式版；重新生成得到的新报告才可以发出去。

### Secondary Metrics

| Metric | Current Baseline | Expected Direction |
|--------|-----------------|-------------------|
| 过期旧链接仍呈现为可转发的正式报告 | 会，只要分享未被人手关闭 | 变为不会 |
| 重新生成后的新报告可以打开并标为当前正式版 | 新报告能生成；与「旧的已过期」没有绑定 | 新报告成为唯一可发出的正式版 |

### Guardrail Metrics

本页不设护栏指标，不进产品度量和实证实验。下面两件事只作为本假设不许被带着一起改掉的结果，不另做实验：

| Metric | Current Value | Acceptable Range |
|--------|--------------|------------------|
| 人手关闭分享后，旧链接返回「已关闭或无效」 | 已实现（公开页 404 HTML） | 保持。不得为了「标过期」而让已关闭链接重新打开 |
| 报告仍只覆盖香港授课型硕士，且不代写文书、不提交申请 | 目的已钉死 | 本假设不扩大范围 |

## Validation Approach

### Method

不是 A/B。一条标本，两项对照。

**先核对每日采集是否真的在跑。没有连续抓取记录，就先修采集，不要先改文案。**

连续的口径：以核对当日为终点，向前数 7 个自然日，每一日都至少有一条 `intelligenceCollectionRuns` 记录，`status` 为完成，且 `finishedAt` 落在该日。缺任何一日、记录为空、或只有无法按日对齐的单次手工跑，都算没有连续抓取记录。

门禁未过：本假设保持未验证。先修采集调度，让上述 7 日记录补齐。此阶段不改报告文案，不加「数据截至」句子。

门禁已过：才做标本。

标本步骤：

1. 用一个已有学生账号，取一份已经打开分享的报告。
2. 在报告正文里点算学费条数和截止日期条数，逐条看是否有抓取日期，并回对情报记录。
3. 更新一条该报告用到的学费或截止日期情报（一次真实采集入库，或一次已审核条目的更新）。
4. 再打开**原来的**分享链接，看它是否还被当作正式版。
5. 重新生成报告，确认只有新报告可以当作正式版发出去。

画像变更走同一条过期规则（画像一变，旧报告同样过期，重新生成后才能发出）。操作者点名的这一条标本只打「情报更新」。PRD 里要把画像和情报写成同一条规则；不要另做 A/B。

### Sample Size & Duration

- 标本：1 份报告，1 个学生账号
- 采集门禁：核对日前 7 个自然日
- 不做流量分配，不做显著性，不估样本量

### Pass/Fail Criteria

- **Validated if:** 采集门禁已过，且标本 2/2：每条学费和截止日期都有可回对的抓取日期；情报更新后旧链接不再是正式版，重新生成的新报告才是。
- **Invalidated if:** 采集门禁已过，但报告上仍有学费或截止日期没有抓取日期，或情报更新后旧链接仍可当作正式版发出。
- **Inconclusive if:** 没有连续抓取记录。此时不判断假设真伪，先修采集，不改文案。

## Risks & Assumptions

### Key Assumptions

- 每日采集若在跑，`intelligenceCollectionRuns` 会留下按日可对的完成记录。没有这张记录，就不能开始改报告。
- 学费和截止日期在情报里是可数的条目（`infoType` 为 `tuition` / `deadline`），报告上能指回某一条，而不是只在散文里提一次「学费」。
- 学生和家长把「能打开的分享链接」当成正式版。链接还开着，就等于还在发出去。
- 画像变更和情报变更用同一条过期规则。标本只演示情报那一侧。

### Risks

- 采集批次在跑，但某条学费或截止日期没有 `fetchedAt`，报告无法标出可回对的日期。这会使假设不成立，不能用页脚文案补上。
- 只把 `is_latest` 改个名字，旧链接仍返回原 HTML。这不算过期。
- 情报更新了，报告引用的仍是旧快照，链接却继续显示为正式版。
- 为了标过期而改写已关闭分享的行为，或顺手改图表、授课边界、家长账号。这些都不在本假设里。
