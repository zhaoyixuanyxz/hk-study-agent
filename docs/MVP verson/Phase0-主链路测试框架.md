# Phase 0：主链路测试框架与验收观测点

**版本**：v1.0  
**阶段**：Phase 0  
**依据**：[MVP-完整任务拆分清单.md](MVP-完整任务拆分清单.md)、[MVP-开发路线确认稿.md](MVP-开发路线确认稿.md)  
**对应 Epic**：`P0-QA-01`

---

## 1. 测试范围说明

本框架覆盖 MVP **端到端主链路**：注册/登录 → 对话建档 → 动态画像 → 单套方案 → HTML 报告 → 历史回看。  
Phase 0 产出**可执行的测试层次与观测点**；具体用例编号与自动化脚本在 Phase 1 起随功能迭代补充。

| 层次 | 内容 | Phase 0 交付 |
|------|------|--------------|
| 主路径 | 各阶段「最小成功路径」 | 本文第 2 节 |
| 异常路径 | 网络失败、鉴权失败、生成失败、恢复失败 | 本文第 3 节 |
| 安全 | 用户数据隔离 | 本文第 4 节 |
| 阶段验收 | 与里程碑对齐的观测点 | 本文第 5 节 |

---

## 2. 主链路用例骨架（按阶段）

| ID | 阶段 | 场景摘要 | 预期（高层） |
|----|------|----------|--------------|
| TC-M-01 | 账号 | 新用户注册并登录 | 获得会话，可访问受保护资源 |
| TC-M-02 | 对话 | 新建会话并连续 3–5 轮发送消息 | 消息持久化、回复连贯 |
| TC-M-03 | 对话 | 关闭页面后同一线程恢复 | 历史消息可加载，可继续发送 |
| TC-M-04 | 画像 | 对话后查看画像 | 摘要/待补充/更新时间与对话事实基本一致 |
| TC-M-05 | 画像 | 跨会话续聊 | 可召回关键记忆（Phase 2 后执行） |
| TC-M-06 | 方案 | readiness 满足后生成方案 | 单套方案含冲刺/匹配/保底与免责 |
| TC-M-07 | 方案 | readiness 不满足 | 明确缺口，不生成或阻断生成 |
| TC-M-08 | 报告 | 生成并打开报告 | 七章可读、字数达标（按 PRD） |
| TC-M-09 | 历史 | 重新登录后查看历史报告/方案 | 仅本人数据可见 |

---

## 3. 异常路径（最少集）

| 类型 | 场景 | 观测点 |
|------|------|--------|
| 网络 | 发送消息中途断网 | 错误提示、可重试、不丢已确认消息（以产品定义为准） |
| 鉴权 | Token 过期或无效 | 跳转登录，不泄露他人数据 |
| 生成 | 方案/报告生成失败 | 可展示错误与重试语义（Phase 3–4） |
| 恢复 | 无效线程 ID | 友好错误，不崩溃 |

---

## 4. 安全与权限观测点

| 观测点 | 验证方法（建议） |
|--------|------------------|
| 水平越权 | 用户 B 的 ID 无法访问用户 A 的会话/画像/方案/报告 |
| 会话绑定 | 所有资源请求携带用户上下文且服务端校验 |

---

## 5. 阶段验收观测点（与里程碑对齐）

| 里程碑 | 观测重点 |
|--------|----------|
| M1（Phase 0–1） | 可对话、多轮、可恢复 |
| M2（Phase 2） | 有画像、有快照、续聊可注入记忆 |
| M3（Phase 3–4） | 有方案、有报告、有历史 |
| M4（Phase 5） | 五页闭环、埋点、QA 通过 |

---

## 6. 典型测试输入样本（草案）

供 Phase 1–4 回归复用，可在实现阶段替换为脱敏真实数据。

| 样本 ID | 描述 | 用途 |
|---------|------|------|
| SAMPLE-A | 信息较完整、目标明确 | 主路径、方案与报告 |
| SAMPLE-B | 关键信息缺口（如预算未填） | readiness 阻断、追问 |
| SAMPLE-C | 冲突或需确认项 | 事实确认流、待确认状态 |

**维护**：样本与 [Phase0-画像快照与planInputView契约.md](Phase0-画像快照与planInputView契约.md) 及 PRD 对齐后定稿。
