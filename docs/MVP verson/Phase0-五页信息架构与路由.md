# Phase 0：五页信息架构与路由草案

**版本**：v1.0  
**阶段**：Phase 0  
**依据**：[MVP-开发路线确认稿.md](MVP-开发路线确认稿.md)、[MVP-完整任务拆分清单.md](MVP-完整任务拆分清单.md)  
**对应 Epic**：`P0-FE-01`

---

## 1. MVP 五页冻结

| 序号 | 页面 | 路由占位 | 核心目标 |
|------|------|----------|----------|
| 1 | 登录 / 注册 | `/login`、`/register`（或合并为 `/auth`） | 建立账号会话 |
| 2 | 智能对话建档 | `/chat` 或 `/conversation` | 多轮对话、中断恢复 |
| 3 | 用户画像 | `/profile` | 摘要、待补充、更新时间 |
| 4 | 方案结果 | `/plan` 或 `/plan/:id` | 单套方案、梯度、免责 |
| 5 | 报告详情 | `/report` 或 `/report/:id` | HTML 七章在线阅读 |

---

## 2. 页面级信息架构（区块级）

### 2.1 登录 / 注册

| 区块 | 内容 |
|------|------|
| 表单 | 账号、密码、必要校验提示 |
| 主操作 | 登录 / 注册 |
| 错误态 | 网络错误、鉴权失败 |
| 空态 | 不适用 |

### 2.2 对话建档

| 区块 | 内容 |
|------|------|
| 消息区 | 历史消息、滚动、加载中 |
| 输入区 | 文本发送、发送中状态 |
| 状态 | 可选：会话恢复提示、加载历史 |
| 异常 | 发送失败、重试 |

### 2.3 用户画像

| 区块 | 内容 |
|------|------|
| 摘要 | 画像摘要 |
| 待补充 | gaps 列表 |
| 元信息 | 更新时间 |
| 空态 | 尚无画像时的引导 |
| 异常 | 加载失败 |

### 2.4 方案结果

| 区块 | 内容 |
|------|------|
| 方案主体 | 冲刺/匹配/保底等结构化展示 |
| 依据与说明 | 解释性文案 |
| 免责 | 固定免责展示（与产品文案一致） |
| 异常 | 生成失败、可重试 |

### 2.5 报告详情

| 区块 | 内容 |
|------|------|
| 正文 | HTML 七章渲染 |
| 元信息 | 更新时间 |
| 空态 | 生成中 |
| 异常 | 加载失败、超时提示 |

---

## 3. 导航与串联

| 决策 | 建议默认 |
|------|----------|
| 登录成功默认落地 | 对话建档页（`/chat`） |
| 对话 → 画像 | 画像就绪或入口按钮跳转 `/profile` |
| 画像/对话 → 方案 | 满足 readiness 后生成方案，跳转 `/plan/:id` |
| 方案 → 报告 | 生成报告后跳转 `/report/:id` |
| 历史入口 | MVP 可采用**报告页或独立列表页**的「历史」入口；具体以 Phase 4 历史 API 为准，Phase 0 仅要求**存在一致的主路径** |

---

## 4. 实现优先级（避免超前开发）

| 优先级 | 说明 |
|--------|------|
| P0 | 先联调壳层：能发消息、拉历史、展示基础 UI |
| P1 | 完整交互与错误态 |
| P2 | 视觉细化与动效 |

非 MVP 页面（院校库、多方案对比等）**不**纳入路由与导航草案。
