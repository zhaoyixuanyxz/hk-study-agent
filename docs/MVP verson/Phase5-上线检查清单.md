# Phase 5：上线检查清单（P5-PM-02）

**版本**：v1.0  
**用途**：试运行 / 内测前逐项确认。

## 安全与合规

- [ ] 生产环境使用 **HTTPS**（反代或托管平台终止 TLS）。  
- [ ] `DEEPSEEK_API_KEY` 等密钥仅环境变量，不入库、不进前端构建产物。  
- [ ] 方案/报告/画像页展示 **免责声明**（与 [Phase3-方案输出规范与文案.md](Phase3-方案输出规范与文案.md)、报告模板一致）。  
- [ ] 用户数据隔离：A 用户 token 不可访问 B 用户 `thread_id` / `plan_id` / `report_id`（已有 API 测试覆盖）。

## 运行与数据

- [ ] `backend/data/db.json`（或 `DATA_FILE`）**定期备份**策略已明确。  
- [ ] `CORS_ORIGINS` 与前端实际域一致。  
- [ ] 健康检查 `GET /health` 可用于探活。

## 性能与容量（基线）

- [ ] `PLAN_GENERATION_TIMEOUT_MS`、`REPORT_GENERATION_TIMEOUT_MS` 与网关超时协调。  
- [ ] 全局限流已开启时（`APP_RATE_LIMIT_*`），压测或手工验证高频请求不会拖垮单进程。  

## 体验

- [ ] 注册 → 登录 → 对话 → 画像 → 方案 → 报告 → 历史 **主路径可走通**。  
- [ ] 清除站点数据后可重新注册/登录并产生新数据（与 QA 用例一致）。
