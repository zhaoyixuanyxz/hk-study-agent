# Phase 3：方案输出规范与文案（产品）

**版本**：v1.0  
**对应 Epic**：P3-PM-01

## 1. 三档策略含义

| 档位 | 含义 | 展示原则 |
|------|------|----------|
| 冲刺（reach） | 在现有背景下偏进取、录取不确定性更高的目标组合 | 强调风险与备选，**不**承诺录取 |
| 匹配（match） | 与背景与目标较一致、可行性相对均衡的组合 | 可作为主路径讨论，仍为建议性质 |
| 保底（safety） | 在可接受前提下更稳妥、不确定性相对较低的方向 | 强调「降低落空风险」而非「保证录取」 |

## 2. 允许与禁止的表述

**允许**：依据用户画像维度（学术、目标、预算、时间、风险偏好）说明建议理由；提示风险、预算与时间线注意事项。

**禁止**：承诺录取、精确录取概率、「一定能进某校」、与院校官方不一致的硬性断言。

## 3. 统一免责声明（模板）

以下文案为 MVP 基线，须出现在方案结果页显著位置（可与技术层 `disclaimer` 字段一致）：

> 本方案由系统根据你提供的信息自动生成，仅供参考，不构成任何录取、签证或财务承诺。具体选校、申请要求与截止时间请以院校及官方渠道为准。

## 4. 失败态话术（用户可见）

| 场景 | 建议话术要点 |
|------|----------------|
| 信息不足 / 未就绪 | 说明尚缺哪些维度或需先完善画像，引导返回对话或确认关键事实 |
| 关键字段未确认 | 提示先完成待确认项，再继续生成 |
| 生成异常 | 提示稍后重试；若持续失败请联系支持（MVP 可简化为「请稍后重试」） |

## 5. 方案结果页最小信息架构

1. 三档卡片：冲刺 / 匹配 / 保底（每档含摘要 + 依据说明）  
2. 整体：风险提示摘要、预算建议、时间线建议  
3. 免责声明（见上）  
4. 失败态：区分「需补信息」与「可重试的技术失败」
