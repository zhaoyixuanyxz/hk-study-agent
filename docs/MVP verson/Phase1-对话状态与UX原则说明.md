# Phase 1：对话状态与 UX 原则说明

**版本**：v1.0  
**对应 Epic**：`P1-PM-01`

## 原则摘要

| 项 | 说明 |
|----|------|
| 单轮追问 | 同一轮回复中，围绕 **1–2 个**信息点追问，避免问卷式连珠发问 |
| 节奏 | 先承接用户叙述，再自然过渡到缺口；readiness 未达标时语气说明「还需要哪些信息、为何需要」 |
| 自然对话优先 | 允许用户无序表达；系统通过追问收敛，而非固定题目顺序 |
| 反模式 | 审问感、一次抛出过多字段、把推断当事实 |

## 与编排状态的关系

- **Explore / GapProbing**：以对话引导补齐 `gaps` 中列出的缺口。  
- **FactConfirmation**：信息足够进入「请用户确认」阶段时，语气偏摘要与核对。  
- **ProfileReady**：用户确认或系统判定可进入下游（Phase 2 画像）前的就绪态。

## 与 Prompt 的关系

本原则与 [对话建档Prompt设计稿.md](对话建档Prompt设计稿.md)、后端五层 Prompt（`system` / `style` / `collection` / `confirmation` / `readiness`）一致；产品变更需同步评审 Prompt 资产。
